# 🌐 IndustrySync — The Industry-Academia Bridge

> **Stop grinding outdated LeetCode problems. Solve real-world tech challenges posted directly by top MNCs, earn XP, and get hired.**

**Live Demo:** [Open index.html directly in browser]  
**Built for:** ANANNAY Ideathon 2025 | PS 4 — Open Innovation  

---

## 1. What It Does

There is a massive gap between outdated university curriculums and the actual skills required by top MNCs. Students lack exposure to real-world engineering problems, and companies waste time training freshers.

**IndustrySync is a platform where:**
1. **Top MNCs (MAANG, etc.)** upload their specific tech stacks, tutorials, and **real-world problems** they are currently facing.
2. **Students** solve these problems. (Rule: Use AI, use your brain, it doesn't matter — just solve the problem, because that's how the real world works).
3. **Gamification:** Students earn XP points and maintain daily streaks.
4. **Direct Hiring:** HRs access a Leaderboard of top-performing students for their specific problem statements and can initiate interviews directly.

---

## 2. The Problem

1. **Curriculum vs Reality:** Colleges teach outdated syllabuses. Students graduate without knowing how modern microservices, rate limiters, or cloud deployments actually work in production.
2. **The "LeetCode" Trap:** Platforms like LeetCode teach theoretical algorithms. An employee in an MNC doesn't reverse linked lists all day; they fix API load times and handle scaling.
3. **The Hiring Inefficiency:** Companies spend 6 months training freshers because their college degree didn't prepare them for actual company work.

---

## 3. Why Existing Tools Fall Short

| Tool | The Gap |
|---|---|
| **LeetCode / HackerRank** | Focuses on competitive programming and 20-year-old algorithmic puzzles. Doesn't reflect real-world company problems. |
| **Traditional University** | Outdated curriculum. No exposure to current MNC tech stacks. |
| **Standard Job Portals** | Based on resumes and degrees, not actual problem-solving capability on modern tech. |

## 5. Architecture & Technical Details

The prototype is built to be extremely fast and easy to demo without any complex setup.

- **Frontend:** Vanilla HTML5, CSS3 (Custom Design System), JavaScript (ES6+).
- **No Dependencies:** Zero `node_modules`. Runs directly in the browser.
- **Routing:** Single Page Application (SPA) logic handled via lightweight JS DOM manipulation.
